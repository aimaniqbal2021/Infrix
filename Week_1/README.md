# ❤️ Heart Drawing App

A simple Python GUI application that uses Tkinter and Turtle Graphics to draw a beautiful heart.

## Features

- Simple graphical user interface
- Draws a heart shape with one click
- Uses Turtle Graphics for drawing
- Beginner-friendly Python project

## Requirements

- Python 3.x
- Tkinter (included with Python)
- Turtle (included with Python)

## How to Run

1. Save the code as `heart.py`
2. Open a terminal in the project folder
3. Run:

```bash
python heart.py
```
